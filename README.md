# Titanic-Dataset---Exploratory-Data-Analysis-EDA-

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic Dataset to identify patterns, trends, relationships, and factors that influenced passenger survival during the Titanic disaster.

The analysis is conducted using Python and popular data analysis libraries such as Pandas, Matplotlib, and Seaborn.

---

##  Objective

The main objectives of this project are:

* Understand the structure of the dataset
* Perform statistical analysis
* Handle and analyze missing values
* Visualize distributions and relationships
* Identify factors affecting survival
* Detect outliers and anomalies
* Draw meaningful business insights from the data

##  Key Findings

### 1. Survival Rate

* Approximately 38% of passengers survived.

### 2. Gender Impact

* Female passengers had a significantly higher survival rate than male passengers.

### 3. Passenger Class Impact

* First-class passengers had the highest survival rate.
* Third-class passengers experienced the highest casualty rate.

### 4. Fare Impact

* Passengers who paid higher fares were more likely to survive.

### 5. Age Distribution

* Most passengers were between 20 and 40 years old.

### 6. Missing Values

* The Cabin column contained a large number of missing values.
* Age also contained missing values requiring attention.

### 7. Outliers

* Fare showed significant outliers due to premium-class tickets.
